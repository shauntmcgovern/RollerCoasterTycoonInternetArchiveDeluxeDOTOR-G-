SETUP AND INSTALLATION
**********************

1. Start Windows 95/98.
2. Insert the RollerCoaster Tycoon CD-ROM game disc into your CD-ROM drive.
3. A title screen should appear. If it doesn't, double-click on the
   "My Computer" icon on your Win95/98 desktop. Next, double-click on
   your CD-ROM icon to install the game. If the install screen still does
   not appear at this point, locate the "setup.exe" file on the RollerCoaster
   Tycoon CD-ROM and double-click on it.
4. Follow the remainder of the on-screen instructions to finish installing
   RollerCoaster Tycoon. You will be prompted for 2 installs,
5. Once installation is complete, double-click on the "PLAY!" RollerCoaster Tycoon: DELUXE!
   game icon to start the game.

Note: You must have the RollerCoaster Tycoon: DELUXE! CD-ROM in the CD-ROM drive to play.

Installation Of Direct X:
*************************
RollerCoaster Tycoon requires DirectX 5.0 or higher in order to run. If you do not
have this installed on your computer, you will be prompted to install DirectX 5.0
while installing the game. Click "yes" when prompted to install DirectX 5.0 and
continue installing the game.

IMPROVING PERFORMANCE
*********************
You can improve game performance by doing one, several, or all of the
following:

1. Select the 'Full' install option during the set-up process.
2. In 'Sound Options' in the game, select 'Minimum Sound Quality'. This will reduce
   the quality and quantity of sound in the game, but will improve speed on slow
   machines.


TROUBLESHOOTING
***************

Problem: The installation procedure installs DirectX 5.0 onto your computer,
	but the game fails with a DirectX error message.
Cure:	Shut down the computer and re-start it, then try running the game again.

Problem: The game locks up or crashes with an obscure error message.
Cure:	This is most likely caused by errors in the Windows drivers for either
	the display card, or sound card. Obtain the latest patches or driver
	upgrades from your computer or card manufacturer, and install them
	before running the game.

Problem: Installing DirectX 5.0 causes the display to become unstable.
Cure:	Boot up Windows 95 in safe-mode (press F8 while booting, then select
	safe mode), then remove all display drivers from System Properties,
	then re-boot and let Windows re-install the display drivers, or run
	Add New Hardware.
   
Problem: No sound or very quiet sound.
Cure:	Check the Windows sound volume and mute control and speaker
	connections.

Problem: Poor game performance when running the game in a window on the
	desktop or using 800x600 or 1024x768 resolutions.
Cure:	Use full-screen 640x480 resolution for best game performance.

Problem: The installer fails when trying to install the game in Japanese
	on a non-Japanese version of Windows 95/98.
Cure:	The Japanese version of the game will only install and function
	correctly when running on Japanese Windows 95/98.



ADDITIONAL GAME PLAYING HINTS
*****************************
Raising/Lowering squares of land:  To raise a single square of land which is
so low it is hidden by surrounding land, increase the area of effect on the
'Land' window, then select the area of land around the hidden square and
raise it, which will pull the hidden square back up to the surrounding level.
